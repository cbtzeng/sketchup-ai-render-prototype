## 配對差值與 95% CI

對 shot 做 10,000 次配對 bootstrap。**回報配對差值，不是各組平均相減** ——
配對能抵銷 shot 之間的難度差異，這是本設計的重點。

| 比較 | Edge F1 差值 | 95% CI | CI 是否排除 0 |
|---|---|---|---|
| C1 − A | +0.1903 | [+0.1338, +0.2468] | 是 |
| C1 − B | -0.0541 | [-0.0928, -0.0153] | 是 |
| C2 − A | +0.1871 | [+0.1342, +0.2400] | 是 |
| C2 − B | -0.0573 | [-0.0996, -0.0149] | 是 |

### 為什麼 C − B 比 C − A 重要

B 組（對 beauty 截圖跑 Canny）是**外部工具用一張截圖就做得到**的事。
C 打贏 A 只證明「有控制圖比沒有好」；C 要打贏 B，才證明
「必須跑在 SketchUp 內部」。若 C − B 的 CI 含 0，結論必須改寫成
「護城河在語意遮罩與相機真值，不在 edge/depth」—— 這是 open-questions Q8 已經決定的立場。
